Projeto ativo
Estrutura

Um projeto conectado.

O domínio principal funciona como ponto de entrada para os recursos do projeto e também participa da integração entre a experiência web e o aplicativo.

Aplicativo Android

Aplicativo desenvolvido em Kotlin, com recursos voltados para segurança, assistência e praticidade.

Experiência web

Uma interface web moderna que apresenta o projeto e seus recursos diretamente pelo navegador.

Associação Android

Este domínio também fornece os recursos necessários para a associação segura entre o site e o aplicativo Android.

Android App Links

Site e aplicativo trabalhando juntos.

Este domínio possui a configuração necessária para permitir que o Android reconheça o aplicativo Mulher Amparada como responsável por determinados links do projeto.

Domínio associado

O domínio oficial utilizado pelo projeto é associado ao aplicativo Android através da verificação de identidade do sistema.
