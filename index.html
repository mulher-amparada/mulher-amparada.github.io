Como funciona

Um pequeno arquivo faz a conexão.

Quando o Android acessa este domínio, ele pode verificar a relação entre o site e o aplicativo. Essa associação permite que determinados links sejam reconhecidos pelo sistema como pertencentes ao aplicativo Mulher Amparada.

01

O navegador acessa o domínio

O endereço web do projeto é utilizado normalmente pelo navegador e também disponibiliza os arquivos necessários para a associação.

02

O Android verifica

O sistema consulta o arquivo de associação hospedado no domínio para confirmar que o aplicativo está autorizado a responder pelos links.

03

O app recebe o link

Com a associação válida, links compatíveis podem ser direcionados diretamente para o aplicativo Mulher Amparada.

Infraestrutura

O que existe por trás do endereço.

O repositório não serve apenas para apresentar uma página. Ele também hospeda a infraestrutura web necessária para a integração com o Android.

Arquivo de associação

O Android utiliza o arquivo assetlinks.json para verificar a relação entre o domínio e o aplicativo instalado.

/.well-known/assetlinks.json

Aplicativo associado

O arquivo informa ao Android qual aplicativo está autorizado a responder pelos links correspondentes ao domínio.

A integração acontece em etapas simples.

01

Um link é acessado

O usuário acessa um endereço pertencente ao domínio do projeto.

02

O Android identifica a associação

O sistema verifica as informações disponibilizadas pelo domínio.

03

O aplicativo é reconhecido

O Android identifica o Mulher Amparada como aplicativo associado ao endereço.

04

O link pode abrir o aplicativo

A navegação pode ser entregue diretamente ao aplicativo em vez de permanecer apenas na página web.
